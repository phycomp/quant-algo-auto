# quant-algo-auto

Quantitative investing, algorithmic trading, and automation skill — covers channel operations (content planning, scripts, SEO, analytics) and trading assistance (strategy development, backtesting, risk management, code templates).

## What it does

- Content planning for YouTube quant/finance channels (12-week templates, 10-min video structure, SEO)
- Strategy development checklist and backtesting validation
- Risk management rules (Kelly, position sizing, drawdown limits)
- Python strategy template (vectorbt)
- Guardrails: no investment advice, always disclose limitations

## Install

```bash
npx skills add phycomp/quant-algo-auto@quant-algo-auto -g -y
```

## Usage

Trigger phrases: "quant trading", "algo trading", "backtesting", "strategy development", "risk management", "position sizing", "trading automation", "YouTube channel strategy for finance/quant content".
